StoryAnalystAI - Agents Technology & Tools Report

This document details the specific technologies, libraries, and tools utilized by each of the autonomous Python Agents in the StoryAnalystAI backend.

1. Website Explorer Agent (agents/website_explorer.py)
   - Purpose: Crawls the target URL to extract the HTML structure, forms, inputs, and links.
   - Technologies & Tools: 
     - requests: For making synchronous HTTP/HTTPS requests to the target website.
     - BeautifulSoup4 (bs4): Used to parse the raw HTML structure and extract specific tags (like <form>, <input>, <a>, <button>).
     - urllib.parse: For normalizing URLs and resolving relative links to absolute links.
   - Note: It operates entirely statelessly without executing Javascript, optimizing for speed.

2. Combined Generator Agent (agents/combined_generator.py)
   - Purpose: Maps the abstract user story conditions (generated by the AI) to the concrete HTML elements (scraped by the Explorer) to generate actionable test steps.
   - Technologies & Tools:
     - Pure Python (dataclasses, re): Relies heavily on Regular Expressions and keyword string matching heuristics. 
   - Note: Operates 100% locally with no LLM dependency, ensuring fast and token-free operations.

3. Test Executor Agent (agents/test_executor.py)
   - Purpose: Autonomously boots up web browsers and executes the generated test cases against the live application.
   - Technologies & Tools:
     - Selenium WebDriver: The core browser automation tool used to click, type, navigate, and take screenshots.
     - webdriver_manager: Automatically downloads and manages the correct matching ChromeDriver binary file for the user's Chrome version.
     - concurrent.futures (ThreadPoolExecutor): Utilized to run multiple test cases in parallel across up to 8 threads, drastically speeding up the execution pipeline.
     - threading.Lock: Used for thread-safe sequential screenshot naming and counter management.

4. Report Agent (agents/report_agent.py)
   - Purpose: Compiles the test execution results (passed, failed, logs, performance timing) into a presentable HTML document.
   - Technologies & Tools:
     - Python string templating: Used to inject execution data into raw CSS/HTML strings.
     - base64: Reads the `.png` screenshots from the file system and encodes them in base64 to embed them directly into the final HTML file. This allows the report to be perfectly portable as a standalone file.
     - datetime: For calculating and presenting precise run-time metrics.

5. Orchestrator (orchestrator.py) - *The Coordinator*
   - Purpose: Not an agent itself, but the brain that coordinates the AI process and triggers the agents.
   - Technologies & Tools:
     - google.generativeai: The official Google SDK used to communicate with the Gemini 2.5 Flash model. Extracts insights from the raw User Story text.
     - JSON / re: Used to sanitize and safely parse the JSON output coming back from the LLM.
     - Rule-Based Engines (engines/rule_analyst.py & rule_generator.py): Custom Python string-parsing modules serving as an unbreakable fallback if the Gemini API goes down or hits rate limits.
